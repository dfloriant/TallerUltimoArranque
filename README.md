# Taller El Último Arranque

Sistema de gestión de órdenes de trabajo para un taller mecánico.

Java 21 · Swing · Oracle Database · JDBC

## Estructura

- `src/main/java/com/taller/modelo`: clases de dominio
- `src/main/java/com/taller/dao`: acceso a datos con PreparedStatement
- `src/main/java/com/taller/vista`: ventanas Swing
- `src/main/java/com/taller/util`: exportación e importación
- `src/main/java/com/taller/excepciones`: excepciones propias
- `sql/`: scripts de creación de tablas y datos de prueba
- `docs/`: diagrama de clases y entidad-relación
